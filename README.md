# Bro Buddies for iPhone

> **Already set up under the old name?** Keep using your existing `chest-day` repository and address: just upload these new files there. Your data stays put, and nothing else changes.

Your workout app as a home-screen app: its own icon, full screen, works with
no signal, and your data stays on your phone. Everything below can be done on
the iPhone itself. It's free, and takes about 10 minutes once.

## 1. Save your data from the current app

In the version you use in Claude: **Progress → Table → Save a full backup**,
and save the file to Files (iCloud Drive is a good place).

## 2. Put the app online, once (free, with GitHub Pages)

An iPhone can only install apps like this from a web address, so the files
need a home. After this step the app runs from your phone, not the internet.

1. In **Files**, tap the zip you downloaded. It becomes a folder of files.
2. In Safari, go to **github.com** and sign up (or sign in).
3. Tap **+** → **New repository**. Name it `bro-buddies`, choose **Public**,
   and tap **Create repository**.
4. Tap **uploading an existing file** → **choose your files**, open the
   unzipped folder, select all the files, then tap **Commit changes**.
5. Open the repository's **Settings → Pages**. Under **Branch**, choose
   `main` and `/ (root)`, then tap **Save**.
6. Wait a minute. Your app is at `https://YOUR-USERNAME.github.io/bro-buddies/`

## 3. Install it

Open that address in **Safari** → tap **Share** → **Add to Home Screen** →
**Add**.

## 4. Bring your data across

Open **the app from your home screen** → **Progress → Table** →
**Restore from a backup…** → pick your backup file → **Replace with this
backup**.

## Good to know

- **Always open it from the home-screen icon.** Safari and the home-screen
  app keep separate data.
- **Your data lives only on this phone.** Tap **Save a full backup** now and
  then and keep the file in iCloud Drive. Deleting the app from the home
  screen deletes its data.
- **It works offline** from the first time you open it.
- **Updating:** upload new files to the same repository, replacing the old
  ones. Then open the app, close it fully, and open it again.
- **The web address is public,** but only the app lives there. Your workouts
  never leave your phone.
- The Claude version keeps working, but the two don't sync. Move data between
  them with a backup file.
