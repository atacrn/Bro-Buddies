How to set up your history sheet
  1. Put a header row at the top with at least Date, Exercise and Weight. Reps, Sets, Workout and Notes are optional.
  2. One row per exercise per day. If you logged every set on its own row, add a Set column: rows for the same day and exercise are combined.
  3. Reps can be one number or one per set, like 5/5/4. 3x5 works too.
  4. Exercise names should match your workouts, like Bench Press. When you check, close misspellings get a suggestion, and new exercises can be added to a workout.
  5. Dates can look like 15 Sep 2026, 2026-09-15 or 15/09/2026.
  6. If an exercise is in more than one workout, add a Workout column to choose.
  7. Weights in pounds? Call the column Weight (lb) and they're converted to kg.
  8. Copy the cells, paste below, and tap Check. Nothing is saved until you tap Import, and you can undo an import straight after.

How to set up your sheet
  1. Put a header row at the top. Only Exercise is required.
  2. Optional columns, in any order: Alternate (add Alternate 2, 3… for more), Sets, Reps, Category, Per hand, Reps per set, Weight per set and Label.
  3. One exercise per row. Alternates take turns, like Bench and Incline. You can also write them in one cell: Bench Press / Incline Bench Press.
  4. Sets and reps can share a cell, like 3x8 or 3 x 6-10.
  5. For the yes/no columns, write yes or leave the cell empty.
  6. Optional: put the workout's name on its own in the top row, above the headers.
  7. Select the cells, copy them, and paste them below.
